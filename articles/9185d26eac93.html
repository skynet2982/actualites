Surface RTX Spark Dev Box : Microsoft lance son mini PC Nvidia pour l’IA locale

Ulrich Rozier

Voir l'article original

Microsoft ouvre les précommandes de la Surface RTX Spark Dev Box, un mini PC à puce Nvidia et 128 Go de mémoire conçu pour faire tourner des modèles d’IA en local. Le prix n’a pas été donné sur scène.

Il existe donc un Windows 11 sans widgets, en thème sombre, avec le mode Ne pas déranger activé d’office. Pour y avoir droit, il faut acheter la Surface RTX Spark Dev Box, le mini PC que Microsoft réserve aux développeurs.

La machine a été éclipsée le 7 octobre par le Surface Laptop Ultra, son port USB-C magnétique, le faux départ de Call of Duty et les souvenirs de Jensen Huang. Elle reste la façon la plus directe de goûter à l’IA locale que Microsoft met en avant, le modèle MAI Code 1.1 Flash compris.

Dévoilée en juin à la conférence Build, la Dev Box embarque la même puce Nvidia RTX Spark que le portable : un processeur Arm à 20 cœurs, un GPU RTX de génération Blackwell et jusqu’à 128 Go de mémoire partagée entre les deux. La différence tient au refroidissement.

Ne soyez plus victime des hackers.

Protégez votre vie numérique avec Bitdefender, la protection européenne de confiance. Bitdefender vous protège contre les arnaques et les fraudes du web. Profitez de vos activités en ligne en toute tranquillité.

Le boîtier encaisse 100 W en continu, quand les PC portables RTX Spark sont prévus pour 45 à 80 W, ce qui compte pour un agent qui tourne toute la nuit.

Le châssis en aluminium imprimé en 3D est percé de 1 000 aérations, clin d’œil aux 1 000 téraflops revendiqués. La connectique comprend deux USB-C, un USB-A, un HDMI, un port Ethernet et une prise casque.

Un Windows préparé pour coder

Microsoft appelle Project Zenith l’image système livrée avec la machine. VS Code, GitHub Copilot dans le terminal, le sous-système Linux et PowerShell 7 y sont installés et configurés, sur une base Windows 11 Pro.

La cible est claire : ceux qui veulent garder leur code et leurs données chez eux, ou faire tourner des agents sans compter les crédits cloud. En face, Nvidia vend sa propre DGX Spark sous Linux, lancée à 3 999 dollars, et Apple son Mac Studio. Pour jouer ou monter des vidéos, un PC classique fera l’affaire pour moins cher.

Les précommandes sont ouvertes depuis le 7 octobre. Microsoft n’a pas donné de prix sur scène, elle est référencée à 5 999,99 dollars sur le Microsoft, et la machine n’était annoncée en juin que pour les États-Unis, via sa boutique en ligne.

Le reste de la soirée est détaillé dans nos autres articles : le portable à 128 Go qui partage la même puce, les IA géantes qui fonctionnent sans Internet, le modèle de code qui réclame 75 Go de RAM, le connecteur Magnetic Connect, Call of Duty absent jusqu’en 2027 et la naissance de Nvidia grâce à Windows 3.1. Microsoft a pris le temps de compter les aérations du boîtier. Le prix attendra.
