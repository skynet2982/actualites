Windows 11 : l’Explorateur de fichiers s’améliore enfin dans la mise à jour KB5040527

Antoine Barsacq

Voir l'article original

Microsoft publiait ce jeudi 25 juillet la mise à jour KB5040527 pour Windows 11. Outre son lot habituel de correctifs pour les bugs introduits dans de précédents patch, cette nouvelle version apporte une nouveauté bienvenue dans l’Explorateur de fichiers.

Ce 25 juillet, Microsoft publiait la dernière mise à jour pour Windows 11. KB5040527 est destinée aux utilisateurs des versions 22H2 et 23H2 du système d’exploitation, avec les numéros de build 22621.3958 et 22631.3958. Comme c’est généralement le cas pour les mises à jour de ce type, elle se concentre principalement sur la correction de bugs, mais ce patch apporte aussi quelques nouveautés.

Principal argument en faveur de l’installation de cette mise à jour mineure : un changement apporté à l’Explorateur de fichiers de Windows 11.

La dernière mise à jour de Windows 11 apporte un tas de correctifs

En mai, l’explorateur de fichiers avait droit à un sacré relooking dans la bêta de Windows 11. Plus moderne, mieux organisé, ce nouvel explorateur de Windows avait de quoi séduire. Certaines de ses améliorations commencent à se faire voir maintenant dans la version stable du système d’exploitation.

Avec KB5040527, il est désormais possible de dupliquer des onglets dans l’Explorateur. Il suffira d’effectuer un clic droit de la souris sur n’importe quel onglet puis de sélectionner l’option “Dupliquer l’onglet” pour créer une copie du dossier visité.

En matière de correctifs, la mise à jour résout tout un tas de problèmes. Voici la liste complète des bugs désormais corrigés avec KB5040527 :

  • Une fuite de mémoire se produit en interagissant avec des dossiers Archive.
  • L’explorateur de fichiers ne répond plus en naviguant dedans.
  • En effectuant une recherche à partir de l’accueil pour la première fois, aucun résultat n’est trouvé.
  • Le menu déroulant de la barre d’adresse peut apparaître de manière impromptue.
  • Lors de l’utilisation de la boîte de dialogue Enregistrer dans la Galerie, une erreur se produit.
  • La boîte de recherche n’affiche pas le nom de dossier correct dans la Galerie.
  • Une zone vide apparaît en haut de l’Explorateur de fichiers.
  • Les boutons Précédent et Suivant de la souris ne fonctionnent pas en survolant la section Fichiers recommandés de l’Accueil.
  • Les images clignotent en les visualisant dans la Galerie.

Comme d’habitude avec les mise à jour de Windows 11, on s’attend maintenant à une nouvelle fournée de bugs. Aux dernières nouvelles, c’était les dernières mises à jour de sécurité qui bloquaient les écrans de certains utilisateurs sur BitLocker. Nul doute que KB5040527 apportera son lot de problèmes aussi, que nous nous chargerons de vous rapporter !

  • Les utilisateurs ont pu découvrir un explorateur de fichiers avec la possibilité de dupliquer un onglet.
  • La mise à jour apporte surtout son lot de correctifs pour des bugs plus ou moins agaçants.
