Laissez-vous guider par nos experts

  • Comment utiliser un code promo sur DxO.com ?

    Pour profiter d’un code promo sur le site DxO, commencez par ajouter les logiciels ou modules souhaités à votre panier. Une fois dans l’espace de paiement, localisez la case "Code promotionnel" située sous le récapitulatif de votre commande. Saisissez-y votre code et cliquez sur "Appliquer". La remise s’affichera immédiatement sur le montant total.

  • Quels sont les différents types de réductions DxO ?

    DxO propose régulièrement plusieurs types de réductions pour ses utilisateurs. Parmi ces offres, on retrouve des offres de lancement avec des remises allant jusqu’à 30 % sur les nouvelles versions de logiciels comme DxO PhotoLab ou Nik Collection. Les anciens utilisateurs bénéficient également de réductions fidélité lorsqu’ils mettent à jour leurs logiciels vers une version plus récente. De plus, des remises saisonnières sont proposées lors des soldes, du Black Friday ou des French Days

  • Les codes promo DxO sont-ils cumulables avec les promotions en cours ?

    En général, les codes promo DxO ne sont pas cumulables avec d’autres offres ou réductions en cours. Si une promotion est déjà active sur un produit, l’ajout d’un code peut ne pas être pris en compte. Toutefois, certaines campagnes ponctuelles peuvent faire exception, notamment pour les offres de mise à jour réservées aux clients existants.
