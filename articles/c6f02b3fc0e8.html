WhatsApp : comment libérer plusieurs Go de stockage sur votre téléphone ?

Votre téléphone manque d’espace et WhatsApp occupe plusieurs gigaoctets de stockage ? Photos, vidéos et documents reçus peuvent rapidement saturer la mémoire de votre smartphone. Découvrez comment repérer les fichiers les plus volumineux sur WhatsApp et supprimer ceux dont vous n’avez plus besoin pour libérer de précieux Go, sans effacer vos conversations importantes.

Messagerie instantanée de Meta, WhatsApp compte parmi les applications les plus utilisées au monde. Seulement l’application peut occuper beaucoup d’espace sur votre téléphone puisque, selon vos paramètres, WhatsApp peut télécharger automatiquement les photos, vidéos et autres médias reçus.

À force d’accumuler ces fichiers, l’application peut occuper plusieurs gigaoctets sur votre smartphone. Une contrainte pour les utilisateurs d’un smartphone de 64 ou 128 Go d’espace maximum. Toutefois, il existe une astuce interne pour vous permettre de faire de la place.

La rédaction vous conseille

Comment libérer de l’espace de stockage sur WhatsApp ?

Il est par exemple possible de réduire la qualité des médias que vous stockez sur votre appareil. Mais ne vous y méprenez pas. Si ces derniers sont nombreux, ils occuperont toujours une certaine place, qu’ils soient d’excellente qualité ou pas.

Pour récupérer de l’espace, WhatsApp intègre un outil souvent méconnu : la gestion du stockage. Il permet de repérer les fichiers volumineux et de supprimer ceux dont vous n’avez plus besoin.

Pour cela, rien de plus simple. Voici la méthode à respecter.

  • Ouvrez l’application ;
  • Cliquez sur les trois petits points en haut à droite de votre écran ;
  • Sélectionnez l’option « paramètres » pour les mobiles Android et « réglages » pour iPhone ;
  • Pour ne pas stocker automatiquement les médias ou gérer leur qualité, sélectionnez l’option « stockage et données » ;
  • Pour retrouver la corbeille de WhatsApp, cliquez sur l’option « gérer le stockage ».

Vous découvrirez à cette occasion l’espace en question qu’occupent l’application et les médias enregistrés sur votre appareil. Pour alléger votre corbeille, cliquez alors sur « passer en revue et supprimer les éléments ».

Ce procédé vous permettra de retrouver tous les médias volumineux actuellement stockés sur votre appareil.

La rédaction vous conseille

Comment supprimer les fichiers volumineux sur WhatsApp ?

Vous pouvez également sélectionner les médias de votre choix. Pour libérer de l’espace de stockage, il est préconisé de supprimer en priorité les plus volumineux.

Cliquez sur l’icône de la poubelle pour supprimer les fichiers sélectionnés.

Si vous supprimez par erreur une photo ou une vidéo, vous pourrez éventuellement la télécharger à nouveau depuis la conversation si le fichier est toujours disponible. Pour éviter toute mauvaise surprise, sauvegardez les médias importants avant de les supprimer.
