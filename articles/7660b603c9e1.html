Le règlement

Le premier cheval gagne : 1 point

Le premier cheval gagne, le second termine deuxième : 2 points

Le deuxième cheval gagne, le premier termine deuxième : 1 point

Le premier cheval est non-partant, le deuxième cheval gagne : 1 point

La sélection gagnante :
Le cheval gagne : POINTS SUPPLEMENTAIRES => rapport PMU Simple Gagnant + rapport PMU Simple Placé
Le cheval se place : POINTS SUPPLEMENTAIRES => rapport PMU Simple Placé

Le bonus "exploit" :
Si dans une course, une équipe est la seule à pronostiquer un cheval ou un couplé gagnant, les points qui lui sont comptés sont doublés
