Ce système d’exploitation GNU/Linux est basé sur la distribution Linux Debian. Il est développé, commercialisé et maintenu par la société Canonical.
Ubuntu existe en deux versions. La version principale stable dit LTS est mise à jour tous les deux ans. La dernière version 18.04, nom de code « Bionic Beaver », est sortie le 26 avril 2018. C'est la version recommandée sur le site de Canonical pour le grand public. La version secondaire propose une mise à jours tous les six mois. La dernière version est la 19.04, nom de code "Disco Dingo", sortie le 16 avril 2019.
Ubuntu est également présent dans le domaine du cloud. Canonical propose un cloud privé entièrement géré et une pile OpenStack entièrement managée.
