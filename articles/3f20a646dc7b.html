    Si votre code promo ne fonctionne pas, voici quelques vérifications à faire :

    • Date d’expiration : Le code peut être expiré.

    • Erreurs de saisie : Vérifiez que le code est bien copié et sans espace en trop.
    • Nombre d’utilisations : Certains codes ne sont utilisables qu’une seule fois par utilisateur.

    Si le problème persiste, consultez les conditions du marchand ou essayez un autre code promo disponible sur Les Numériques.
