Si vous utilisez Copilot, il va probablement y avoir du changement très prochainement dans votre application, car Microsoft a décidé de fusionner plusieurs de ses offres pour simplifier l'expérience.

Il y a quelques semaines, le patron de Microsoft Satya Nadella déclarait que d'ici la fin de l'année Copilot aurait une "super app" regroupant toutes les fonctionnalités de l'IA. À l'instar d'OpenAI et les branches de ChatGPT notamment, les utilisateurs de Copilot pourront ainsi accéder à différents outils comme le chat, Cowork, Code et Autopilots sans avoir à jongler entre plusieurs endroits. Le début de ce chantier a déjà commencé avec une simplification bienvenue des offres individuelles de Copilot.

Microsoft combine ses applications Copilot pour y voir plus clair

Pour commencer, il est question de la fusion de l'application Copilot (à destination du grand public) avec Microsoft 365 Copilot (à destination des professionnels et des entreprises) au sein d'une "nouvelle application". Le nom Microsoft Copilot va rester, mais une nouvelle icône mêlant les couleurs des deux applications qui ne vont plus en faire qu'une sera de la partie.

Cette nouvelle application proposera le Chat et la génération d'images, mais aussi des accès aux applications Microsoft 365 (Word, Excel, Outlook...) pour y connecter du contenu. Quel que soit le type de compte utilisé, l'historique et le contenu des utilisateurs seront migrés vers la nouvelle application. Si plusieurs types de comptes sont utilisés, notamment pour les personnes qui utilisent à la fois Copilot et Microsoft 365 Copilot, les données restent séparées dans l'application.

Cette nouvelle expérience unifiée, dont les multiples détails spécifiques peuvent être trouvés dans le lien en source, va être déployée en deux temps. Dès mi-août, il sera question d'un déploiement sur mobile et les web apps. Pour les applications Windows et macOS, il faudra attendre mi-septembre. Notons qu'il n'est pas ici encore question de l'autre version de Copilot dédiée au code, GitHub Copilot.

Certains éléments vont à l'inverse être retirés de Copilot. Dès le 18 août, les fonctionnalités podcasts, conversation de groupe et recherche approfondie (sauf pour les utilisateurs Microsoft 365 Premium pour cette dernière) vont ainsi disparaitre. Même chose pour le compagnon Mico, la mascotte qui s'affiche actuellement lors de l'utilisation du mode vocal de Copilot. À l'avenir, il ne sera présent que durant le mode apprentissage de Copilot.
