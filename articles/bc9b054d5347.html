Le sous-système Windows pour Linux offre aux développeurs une excellente raison de rester fidèles à Microsoft : voici pourquoi

Steven Vaughan-Nichols

Voir l'article original

Les points clés à retenir sur Windows Subsystem pour Linux (WSL) 3

  • WSL 3 renforce les capacités de Linux sous Windows.
  • Linux bénéficie d'un accès plus direct aux GPU et aux NPU.
  • Un bureau Linux pur reste la meilleure option pour les développeurs en IA.

Microsoft fait un pas de plus vers un bureau Linux avec la sortie en version bêta du Windows Subsystem for Linux (WSL) 3.

Lors de la conférence Microsoft Build 2026 à San Francisco, Microsoft a présenté WSL 3 comme la prochaine étape de son histoire « Linux sur Windows ». La société a présenté le système comme une fonctionnalité en avant-première qui sera progressivement déployée sur l'ensemble de la base Windows 11.

Comme pour les versions précédentes, le système est proposé sous forme de composant gratuit pouvant être mis à jour indépendamment de Windows via les canaux de distribution WSL existants, plutôt que sous la forme d'une référence de produit distincte.

Quelle évolution pour WSL 3 ?

WSL 3 ne marque pas tant une rupture totale avec ses prédécesseurs qu’un pivot architectural.

  • WSL 1 s’appuyait sur la traduction des appels système pour exécuter les binaires Linux
  • WSL 2 est passé à une machine virtuelle (VM) gérée et légère qui exécute un véritable noyau Linux

WSL 3 conserve l'expérience familière du shell WSL. De plus, vous pourrez exécuter des conteneurs Linux sous WSL 3.

Le changement important dans WSL 3 réside dans la manière dont les processus Linux communiquent avec le matériel sous-jacent, l'accent étant mis sur la réduction au minimum des couches entre l'espace utilisateur Linux et les périphériques Windows.

Gains de performances

Microsoft a promis que WSL 3 vous apporterait « des GPU et des NPU sans perte de performances ».

Sous WSL 2, Microsoft avait ajouté la prise en charge des GPU et amélioré l'intégration graphique. Mais ces fonctionnalités fonctionnaient toujours via la machine virtuelle.

La surcharge liée au changement de contexte et à la traduction qui en résultait impliquait que vous deviez composer avec des ralentissements lorsque vous aviez besoin de GPU et de NPU. Cette approche convenait à de nombreux workflows de développement, mais elle limitait considérablement vos performances lors du traitement de charges de travail d’IA, même si votre PC était équipé de NPU dédiés.

WSL 3 améliore les performances en mettant en œuvre une nouvelle approche de machine virtuelle paravirtualisée. La paravirtualisation offre à la fois une machine virtuelle et un accès au matériel natif. Selon Microsoft, « cela signifie que les conteneurs Linux s'exécuteront désormais directement sous Windows, sans configuration supplémentaire requise ». Cette approche me semble intéressante.

Un gain de performances aussi sur les PC Copilot+ (pour Qualcomm et Intel seulement)

Le chemin d'exécution repensé de WSL 3 réduit la surcharge en intégrant plus directement des accélérateurs dans l'environnement Linux. De cette manière, les frameworks d'IA tels que PyTorch ou TensorFlow s'exécutant au sein de WSL bénéficieront de performances bien plus proches de celles qu'ils obtiendraient sur un hôte Linux natif.

Microsoft a décrit cette stratégie comme faisant de WSL 3 le moyen le plus rapide d'exécuter des charges de travail d'IA basées sur Linux sur un PC Windows, à l'exception de l'exécution de Linux en mode bare metal.

Plus précisément, vous constaterez un gain de performances sur les PC Copilot+ et sur les ordinateurs dotés des architectures suivantes :

  • Qualcomm Snapdragon X Elite
  • Intel Meteor Lake
  • Intel Lunar Lake

La prise en charge des puces AMD ne sera pas disponible dans un premier temps.

Le choix entre plusieurs distributions Linux pour les VM

La nouvelle conception ressemble toujours à « simplement WSL » du point de vue de l'utilisateur. Le système est invoqué à l'aide de commandes wsl et intégré à Windows. Mais en coulisses, la nouvelle conception modifie la manière dont les périphériques et les accélérateurs sont présentés à Linux.

Cette approche s'inscrit parfaitement dans la vision plus large de Microsoft concernant les PC IA. Le matériel Windows configuré autour de GPU et de NPU pourra désormais exécuter localement et rapidement des charges de travail IA. Microsoft souhaite que WSL 3 serve de pont permettant aux piles IA axées sur Linux de tirer parti du matériel sans obliger les développeurs à quitter Windows.

Remarquez toutefois que si vous voulez vraiment bénéficier de la meilleure expérience de développement IA, vous devriez vraiment utiliser une distribution Linux sans Windows. Cependant, si vous êtes coincés avec Windows, comme c'est le cas de nombreux programmeurs en raison de politiques technologiques obsolètes, WSL 3 constituera une bonne alternative.

Avec WSL 3, tout comme avec WSL 2, vous aurez le choix entre plusieurs distributions Linux en machine virtuelle. Actuellement, les options incluent Ubuntu, Debian, OpenSUSE, Kali, Alpine et d’autres.

WSL est devenu open source mi-2025, bien que certains composants du mode noyau et du système de fichiers restent propriétaires.

Comment accéder à WSL 3 ?

Microsoft devrait intégrer plus complètement WSL 3 dans la distribution WSL standard. Votre expérience « wsl » par défaut sur les nouvelles machines Windows sera alors WSL 3. Je m'attends à ce que ce changement arrive dans Windows 11 26H2 cet automne.

Bien que vous puissiez télécharger WSL 2 depuis GitHub dès aujourd’hui, WSL 3 n’y est pas encore disponible. Pour essayer les dernières fonctionnalités de WSL, vous devez plutôt rejoindre le programme Windows Insider et utiliser un canal de préversion.

Heureusement, le programme Insider est beaucoup plus facile à utiliser qu'auparavant. Une fois que vous êtes sur un canal proposant l'aperçu de WSL 3, qui n'est pas disponible à la date du 13 juin 2026, les mises à jour WSL arrivent avec la version du système d'exploitation et le package WSL Store/MSI :

Voici comment participer :

  1. Rejoignez le programme Windows Insider et choisissez un canal Dev/Beta sur un ordinateur Windows 11.
  2. Assurez-vous d'utiliser une version Insider récente postérieure aux annonces de la version 2026 (celles qui, selon les informations, incluraient WSL 3).
  3. Installez WSL (si vous ne l'avez pas déjà). Ouvrez ensuite une fenêtre PowerShell avec des privilèges administrateur, exécutez la commande wsl --install et redémarrez lorsque vous y êtes invité.
  4. Laissez Windows télécharger le dernier package WSL et le dernier noyau ; sur les versions Insider, cela inclura la préversion de WSL 3 dès qu'elle sera disponible.

La nouvelle architecture est intégrée au même shell Bash Linux

À partir de là, les commandes shell wsl --version et wsl --list --verbose vous indiqueront la version de WSL et l'état de la distribution. La nouvelle architecture est intégrée au même shell Bash Linux.

Si vous ne souhaitez pas faire passer l'ensemble de votre système d'exploitation en canal de préversion (et qui pourrait vous en vouloir ?), Microsoft documente également une méthode pour obtenir la dernière préversion de WSL via le package autonome et le drapeau de préversion :

  1. Installez WSL, si nécessaire, avec PowerShell en mode administrateur : wsl --install, puis redémarrez.
  2. Mettez à jour WSL vers la dernière version préliminaire en exécutant, en tant qu'administrateur : wsl --update --pre-release.
  3. Vous pouvez également récupérer la dernière version du programme d'installation Microsoft (MSI) de WSL directement depuis la page des versions GitHub de Microsoft/WSL et l'installer pour vous assurer de disposer du paquet le plus récent.

Utiliser un double démarrage Windows/Linux ?

Donc, si vous souhaitez devenir programmeur IA et que votre entreprise refuse de vous laisser utiliser un bureau Linux natif, ou si vous êtes simplement un utilisateur inconditionnel de Windows, je vous conseille d'essayer WSL 3.

Une autre option consiste à utiliser un double démarrage Windows/Linux.

Le point essentiel à retenir est que Microsoft mise davantage sur WSL en tant qu'élément central de l'histoire des développeurs Windows, et non plus comme un simple outil de niche. L'accent mis par WSL 3 sur les performances et son intégration plus étroite avec les accélérateurs indiquent que si vous développez ou exécutez des charges de travail d'IA, de conteneurs ou de développement basées sur Linux, Microsoft souhaite que vous puissiez le faire confortablement sous Windows, ce qui correspond exactement au public que WSL 3 vise à conquérir.
