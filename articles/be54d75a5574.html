Le prix du Xbox Game Pass dépend de la formule choisie. Microsoft propose aujourd’hui plusieurs abonnements, allant de l’offre Essential à la formule Ultimate, la plus complète. Les joueurs PC disposent également d’un abonnement spécifique.

Quel abonnement Xbox Game Pass choisir ?

Le meilleur abonnement Xbox Game Pass dépend avant tout de votre façon de jouer.

Choisissez le Game Pass Essential si :
vous cherchez avant tout l’abonnement Xbox le moins cher, souhaitez jouer en ligne et n’avez pas besoin de l’ensemble du catalogue Game Pass.

Choisissez le Game Pass Premium si :
vous souhaitez profiter d’un catalogue de jeux plus important et de davantage d’avantages, sans nécessairement avoir besoin de tout ce qui est inclus dans Ultimate.

Choisissez le PC Game Pass si :
vous jouez exclusivement sur PC. Il est inutile de payer pour les avantages Xbox inclus dans Ultimate si vous ne possédez pas de console Xbox.

Choisissez le Game Pass Ultimate si :
vous jouez sur Xbox et PC, utilisez le Cloud Gaming ou souhaitez tout simplement profiter de l’offre Xbox Game Pass la plus complète avec la disponibilité de jeux dès le premier jour de leur sortie.

Pour la majorité des joueurs possédant une Xbox et cherchant surtout à jouer en ligne, Essential peut donc suffire. Pour ceux qui consomment plus de jeux ou qui veulent profiter de nouveaux jeux chaque mois dans l’abonnement, l’offre Ultimate devient bien plus intéressante.

Xbox Game Pass Essential : prix et avantages

Le Xbox Game Pass Essential constitue la porte d’entrée de l’écosystème Game Pass. Son prix est actuellement de 8,99 € par mois.

Il s’adresse notamment aux joueurs qui souhaitent jouer en multijoueur en ligne sur Xbox sans nécessairement souscrire à l’offre Game Pass la plus chère.

Le Game Pass Essential comprend notamment :

  • Plus de 50 jeux disponibles
  • L’accès au multijoueur en ligne sur console
  • Gagne des points Rewards
  • Cloud gaming illimité sur les jeux proposés

C’est donc l’abonnement Xbox à privilégier si votre priorité est de payer le moins cher possible tout en conservant l’accès aux fonctionnalités essentielles sur console.

Quel est le prix du Game Pass Essential sur 12 mois ?

Au tarif mensuel de 8,99 €, douze mois de Game Pass Essential représentent 107,88 € par an. Selon les offres disponibles, des codes ou abonnements de plusieurs mois peuvent également être proposés par différents revendeurs.

Xbox Game Pass Premium : prix et avantages

Le Xbox Game Pass Premium se positionne entre Essential et Ultimate. Proposé à 12,99 € par mois, il s’adresse aux joueurs qui souhaitent accéder à une offre plus complète qu’Essential sans nécessairement payer le prix demandé pour Ultimate. Le Game Pass Premium comprend notamment :

  • Plus de 200 jeux disponibles
  • Nouveaux jeux publiés par Xbox dans l’année suivant leur lancement
  • L’accès au multijoueur en ligne sur console
  • Gagne 2x plus de points Rewards
  • Cloud gaming illimité sur les jeux proposés

Premium constitue ainsi le compromis entre prix et catalogue au sein de la gamme Game Pass. C’est également l’une des principales différences avec Essential. L’abonnement Premium s’adresse davantage aux joueurs qui utilisent régulièrement le catalogue Game Pass, tandis qu’Essential répond davantage aux besoins de base d’un joueur Xbox.

PC Game Pass : prix et avantages

Le PC Game Pass est, comme son nom l’indique, entièrement destiné aux joueurs PC. Son prix est actuellement de 12,99 € par mois. Il permet notamment de profiter :

  • Plus de 300 jeux disponibles
  • De nouveaux jeux disponibles dès le jour de leur sortie
  • EA Play
  • Gagne 2x plus de points Rewards

Si vous jouez uniquement sur PC, le PC Game Pass est généralement plus intéressant que le Game Pass Ultimate, puisque vous ne payez pas pour les fonctionnalités spécifiquement destinées aux consoles Xbox. En revanche, les joueurs qui alternent régulièrement entre PC et Xbox ouCloud Gaming auront davantage intérêt à regarder du côté de l’abonnement Ultimate.

Xbox Game Pass Ultimate : prix et avantages

Le Xbox Game Pass Ultimate est l’abonnement le plus complet proposé par Microsoft. Il coûte actuellement 20,99 € par mois (moins cher avec notre astuce plus bas) et regroupe de nombreux avantages des autres formules Game Pass. Il comprend notamment :

  • Plus de 500 jeux disponibles
  • De nouveaux jeux disponibles dès le jour de leur sortie
  • Abonnement EA Play, Club de Fortnite et Ubisoft+ Classics compris
  • L’accès au multijoueur en ligne sur console
  • Gagne 4x plus de points Rewards
  • Cloud gaming illimité sur les jeux proposés

Ultimate est donc principalement destiné aux joueurs qui souhaitent profiter au maximum de l’écosystème Xbox, notamment sur plusieurs appareils, mais aussi à ceux qui souhaitent jouer tout de suite aux jeux dès leur sortie. Essential ou Premium : lequel choisir ?

La principale différence entre Game Pass Essential et Premium concerne le nombre jeux disponibles dans l’abonnement. L’abonnement Essential n’en comporte que très peu finalement, il faut le voir comme une offre découverte.

Essential est donc préférable si vous recherchez avant tout un abonnement Xbox peu cher, tandis que Premium devient plus intéressant si vous utilisez régulièrement le catalogue Game Pass.

Game Pass Premium ou Ultimate : quelles différences ?

C’est probablement le choix le plus difficile. Le Game Pass Premium coûte moins cher et propose déjà plus de 200 jeux, tandis qu’Ultimate ajoute notamment de nouveaux jeux disponibles dès le jour de leur sortie, sans devoir attendre un an. Pour résumer :

  • Premium → meilleur compromis entre prix et catalogue.
  • Ultimate → meilleur choix si vous voulez absolument tous les avantages du Game Pass.

uel abonnement Xbox faut-il pour jouer en ligne ?

Pour jouer en ligne aux jeux multijoueur payants sur Xbox, toutes les formules Game Pass permettent maintenant d’accéder au multijoueur, ce qui n’était pas le cas avant 2025.

Il n’est donc pas nécessaire de posséder l’abonnement Ultimate simplement pour jouer en ligne. Si votre seul objectif est par exemple de jouer en multijoueur à Call of Duty, EA Sports FC ou GTA Online, l’abonnement Xbox le moins cher donnant accès au multijoueur est généralement le choix le plus logique.

À noter que les jeux free-to-play ne nécessitent pas d’abonnement Game Pass pour jouer en ligne. Fortnite, Warzone, Apex Legends ou encore Rocket League peuvent donc être joués en multijoueur sans abonnement Xbox payant.

Quel abonnement Xbox remplace le Xbox Live Gold ?

Le Xbox Live Gold n’existe plus sous son ancienne forme. Microsoft avait initialement remplacé le service par le Xbox Game Pass Core en septembre 2023. Depuis, la gamme Game Pass a de nouveau évolué et le Game Pass Essential occupe désormais cette place dans l’écosystème Xbox.

Si vous recherchez aujourd’hui un abonnement Xbox principalement pour jouer en ligne, il n’est donc plus nécessaire de chercher un abonnement Xbox Live Gold. Il faut désormais se tourner vers l’offre Essentiel ou vers l’une des formules Game Pass supérieures qui incluent également le multijoueur en ligne.

Quelle est la meilleure offre Xbox Game Pass ?

Il n’existe pas un abonnement Game Pass qui soit objectivement meilleur pour tout le monde. Le meilleur rapport qualité/prix dépend surtout de votre profil :

  • Vous voulez simplement jouer en ligne sur Xbox → Essential
  • Vous voulez un catalogue plus important sans payer Ultimate → Premium
  • Vous jouez uniquement sur PC → PC Game Pass
  • Vous voulez la formule la plus complète et tous les jeux dès qu’ils sortent → Ultimate

Avant de vous abonner, regardez donc surtout les fonctionnalités dont vous avez réellement besoin plutôt que de choisir automatiquement la formule la plus chère.

Questions fréquentes sur le Xbox Game Pass

Combien coûte le Xbox Game Pass ?

Le prix dépend de l’abonnement choisi. Le Game Pass Essential coûte actuellement 8,99 €/mois, Premium 12,99 €/mois, le PC Game Pass 12,99 €/mois et Ultimate 20,99 €/mois en prix publics. Notre astuce permet cependant d’avoir l’offfre Ultimate à 10 € par mois environ.

Quel est l’abonnement Xbox le moins cher ?

Xbox Game Pass Essential est actuellement la formule Game Pass la moins chère proposée aux joueurs Xbox, avec un tarif de 8,99 € par mois.

Quelle différence entre Game Pass Premium et Ultimate ?

Premium propose 200 jeux, tandis qu’Ultimate ajoute 500 jeux PC et consoles, ainsi que de nouveaux jeux disponibles dès le jour de leur sortie. Ultimate coûte donc plus cher, mais constitue l’abonnement le plus complet et le plus intéressant quand on joue régulièrement.

Quel Game Pass faut-il pour jouer en ligne ?

L’offre Essential (anciennement Core) suffit pour accéder au multijoueur en ligne sur les jeux Xbox payants. Les offres supérieures incluent également cette fonctionnalité. Les jeux free-to-play ne nécessitent aucun abonnement Game Pass pour leur multijoueur.

Le PC Game Pass fonctionne-t-il sur Xbox ?

Non. Le PC Game Pass est destiné aux jeux PC. Si vous souhaitez profiter du Game Pass à la fois sur PC et Xbox, il faut regarder les avantages proposés par les autres formules, notamment Ultimate.

Est-ce que le Game Pass Ultimate comprend le PC Game Pass ?

Oui, l’offre Ultimate comprend tout ce que propose le PC Game Pass.

Les jeux Xbox Game Pass restent-ils disponibles définitivement ?

Non. Le catalogue Game Pass évolue régulièrement et certains jeux tiers quittent le service. Les titres concernés sont généralement annoncés à l’avance par Microsoft. Les conditions peuvent être différentes pour les jeux appartenant directement à Microsoft. Suivez bien Xboxygen pour être au courant des nouveaux jeux ajoutés ou de ceux qui sont retirés du catalogue.

Peut-on résilier le Xbox Game Pass à tout moment ?

Oui. Vous pouvez désactiver la facturation récurrente depuis votre compte Microsoft. Vous conservez alors les avantages de votre abonnement jusqu’à la fin de la période déjà payée.

Comment résilier l’abonnement Xbox Game Pass ?

Pour résilier un abonnement Xbox Game Pass, il faut aller dans la gestion de l’abonnement Xbox Game Pass et des autres abonnements Xbox.

  • Depuis la console Xbox :
    • Aller dans les « Paramètres et Comptes » de la console
    • Choisir l’abonnement Xbox Game Pass
    • Annuler l’abonnement
  • Depuis le site Microsoft
    • Se connecter au site Microsoft
    • Aller dans la page des abonnements
    • Cliquer sur “gérer” en face de votre abonnement Xbox Game Pass
    • Choisir “Annuler l’abonnement”
    • Valider

Est-ce que le Xbox Game Pass fonctionne avec le partage de compte ?

Oui, l’abonnement Xbox Game Pass fonctionne avec le partage de compte Xbox sans problème, comme ce fut le cas avec l’abonnement Xbox Live Gold. Avec une petite subtilité tout de même : seul le titulaire de l’abonnement est en mesure de consulter le catalogue de l’offre et donc de lancer l’installation d’un jeu. L’autre compte doit donc aller dans la section “Prêt pour l’installation” de sa console pour installer les jeux.

Est-il possible de jouer aux jeux du Game Pass en étant hors ligne ?

Oui, si vous disposez d’un abonnement en cours de validité, vous pouvez jouer sans être connecté à internet à tous les jeux du service que vous avez installés au préalable, ce dans la limite de votre période d’abonnement, soit 30 jours maximum. Au-delà de cette période, la console devra se connecter à nouveau pour vérifier la validité de votre abonnement.

Notez que comme pour tout jeu dématérialisé, cela n’est possible que sur votre “Xbox principale” et qu’il sera donc impossible de jouer hors ligne si vous partagez votre compte.

Est-ce que je peux continuer de jouer aux jeux si l’abonnement Xbox Game Pass est terminé ?

Il faut un abonnement en cours de validité pour pouvoir jouer aux jeux du Game Pass. Les jeux ne sont pas pour autant désinstallés hors abonnement. Ils restent installés sur votre console, mais il ne vous sera plus possible de les lancer. Pour continuer à jouer, vous serez alors invité à renouveler votre abonnement ou à acheter le jeu.

Pendant combien de temps peut-on utiliser le Xbox Game Pass ?

L’accès aux jeux du Xbox Game Pass est illimité tant que vous payez un abonnement Xbox Game Pass. Si votre abonnement expire ou que vous l’annulez, l’accès aux jeux cessera.

Comment jouer à un jeu retiré du Xbox Game Pass ?

Une fois qu’un jeu est retiré du catalogue Xbox Game Pass, il n’est plus possible d’y jouer via votre abonnement. Il faut alors acheter le jeu en version physique dans le commerce, ou en version dématérialisée pour continuer à y jouer.

Est-ce qu’un jeu supprimé du Game Pass est supprimé du disque dur ?

Non, lorsqu’un jeu disparaît du Xbox Game Pass, il reste dans votre disque dur. Si vous avez acheté le jeu, vous pourrez continuer d’y jouer. Si vous ne l’avez pas acheté et que vous l’utilisiez uniquement via le service Game Pass, il faudra acheter le jeu pour continuer d’y jouer.

Combien de temps un jeu reste-t-il dans le Xbox Game Pass

Les jeux disponibles dans le catalogue Xbox Game Pass, PC Game Pass ou Xbox Game Pass Ultimate ne restent pas indéfiniment dans le catalogue. Nous avons calculé qu’en moyenne, un jeu reste dans le Xbox Game Pass pendant 21 mois avant d’être retiré. Certains restent pendant 6 mois et d’autres 2 ans, continuez de suivre l’actualité Xbox Game Pass sur Xboxygen pour être informé des jeux retirés tous les mois.

Quelles sont les changements majeurs apportés aux offres Game Pass ces dernières années ?

  • Juin 2017 : lancement du Xbox Game Pass console.
  • Juin 2019 : lancement du Xbox Game Pass PC.
  • Septembre 2020 : lancement du Xbox Game Pass sur mobile via Android
  • Septembre 2020 : Le catalogue de jeux EA Play est intégré au Xbox Game Pass Ultimate et PC.
  • Juin 2021 : lancement du Xbox Game Pass sur PC et iPhone et iPad via iOS. Le service Cloud est également alimenté par des Xbox Series X désormais.
  • Septembre 2023 : lancement du Xbox Game Pass Core en remplacement du Xbox Live Gold
  • Juillet 2024 : fin du Xbox Game Pass Console au profit du Xbox Game Pass Standard qui intègre le jeu en ligne ainsi qu’un catalogue de 400 jeux, mais perd l’accès aux jeux Xbox dès le jour de leur sortie.
  • Octobre 2025 : Xbox remanie ses offres et augmente le prix des abonnements Core (devenu Essential), PC et Ultimate.
