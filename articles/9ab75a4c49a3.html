Top 14. Les compositions officielles d'UBB - Montpellier : Louis Favrau à l'ouverture, Jon Echegaray de retour

Par La rédaction de Rugbyrama

Voir l'article original

C'est avec une équipe remplie de jeunes joueurs que l'UBB reçoit Montpellier ce samedi à Chaban-Delmas. Découvrez les compositions des deux équipes.

Le XV de départ de l'UBB : 15. Mousquès ; 14. Uberti, 13. Depoortere (cap.), 12. Janse van Rensburg, 11. Avogadro ; 10. Favrau, 9. Retière ; 7. Ibsaiene, 8. T. Willis, 6. Bochaton ; 5. Cazeaux, 4. Palu ; 3. Sadie, 2. Sa. 1. Perchaud.

Remplaçant : 16. Malinowski, 17. Pkhakadze, 18.Tameifuna, 19.Moon, 20. Matiu, 21. Hutteau, 22. Penaud, 23. Duguay.

Le XV de départ de Montpellier : 15. Echegaray ; 14. Rates, 13. Vincent, 12. Anyanwu, 11. D. Taofifenua ; 10. Hastings, 9. Bernadet ; 7. Masibaka, 8.Vunipola, 6. Nouchi (cap.) ; 5. Perrin, 4. Van Heerden ; 3. Japaridze, 2. Akrab, 1.Tabarot.
