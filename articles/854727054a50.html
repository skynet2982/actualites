Vous pourrez bientôt réinstaller Windows 11 à partir de zéro, même si le système ne parvient pas à démarrer. Voici comment procéder

Lance Whitney

Voir l'article original

Les points clés à retenir sur la nouvelle fonction « Reconstruction dans le cloud » de Windows

  • Microsoft présente en preview un nouvel outil de récupération appelé « Cloud Rebuild ».
  • Cette fonctionnalité permettra de réinstaller Windows 11 « à zéro » de manière propre.
  • « Cloud Rebuild » peut s’avérer utile si Windows lui-même ne démarre plus.

Avez-vous déjà rencontré un problème grave sur votre PC Windows, au point que le système d’exploitation refuse de se charger ? Moi aussi. Vous avez probablement paniqué en vous demandant frénétiquement quoi faire. Même avec les bons outils de récupération, parvenir à faire démarrer correctement Windows dans ce genre de situation relève souvent du hasard. Eh bien, Microsoft dévoile une nouvelle fonctionnalité qui promet de réduire votre panique et de redonner vie à Windows.

Actuellement en mode préversion, la nouvelle option « Cloud Rebuild » vise à restaurer Windows dans un état vierge, même si le système d’exploitation ne démarre pas. L’objectif est ici de fournir une version propre du système d’exploitation, sans les pilotes, fichiers ou autres éléments susceptibles d’avoir causé le dysfonctionnement au départ. Mais ce n’est pas tout.

Au-delà de la simple restauration d’un Windows « propre », la « reconstruction dans le cloud » ajoutera les dernières mises à jour grâce à Windows Update. Cela garantit que le système d’exploitation est doté des derniers correctifs de sécurité et autres mises à jour essentielles, vous évitant ainsi de perdre du temps à les installer manuellement.

Au delà de « Réinitialiser ce PC »

Windows propose depuis longtemps une option appelée « Réinitialiser ce PC », qui ramène également le système d’exploitation à un état vierge. Mais celle-ci vous oblige à installer vous-même les dernières mises à jour.

« Contrairement à “Réinitialiser ce PC”, la fonctionnalité “Cloud Rebuild” télécharge à la fois l’image Windows cible et les pilotes de l’appareil depuis Windows Update. L’appareil redevient ainsi pleinement fonctionnel sans support USB, sans image personnalisée et sans dépendre de l’état de santé du système d’exploitation actuellement installé », a déclaré Microsoft dans un document décrivant la nouvelle fonctionnalité.

Le seul inconvénient est que les fichiers personnels, les paramètres personnalisés ou les applications installées ne seront pas conservés. Vous devrez les rajouter vous-même. C’est pourquoi il est important de toujours sauvegarder ou synchroniser votre PC afin de pouvoir restaurer facilement ce dont vous avez besoin, même si Windows doit être réinstallé à partir de zéro.

Comment essayer la reconstruction dans le cloud

Avec Cloud Rebuild en mode prévisualisation, vous aurez besoin de la dernière version Insider de Windows 11 pour l’essayer, plus précisément la version de prévisualisation 26300.8772 ou une version ultérieure. Assurez-vous d’exécuter cette version sur un PC de test ou dans un environnement virtuel afin de ne pas affecter votre système principal.

Pour tester la fonctionnalité « Cloud rebuild » dans la version de préversion de Windows, assurez-vous que votre PC est connecté à Internet via Ethernet ou Wi-Fi. Sous Windows, accédez à Paramètres, sélectionnez Système, puis cliquez sur Récupération. Sous Options de récupération, cliquez sur le bouton « Redémarrer maintenant » à côté de Démarrage avancé.

Sur l’écran de l’environnement de récupération Windows (WinRE), sélectionnez Dépannage, cliquez sur Récupération et désinstallation, puis cliquez sur Reconstruction dans le cloud. Vérifiez la version, l’édition et la langue de Windows cibles, puis cliquez sur Continuer. L'écran suivant vous informe que ce processus supprimera tous vos fichiers personnels, comptes, applications, programmes et paramètres personnalisés. Si vous acceptez cette condition, cliquez sur « Installer » pour continuer. Une fois Windows reconstruit avec les dernières mises à jour, vous pourrez vous connecter au bureau.

Quand la fonctionnalité « Reconstruction dans le cloud » sera-t-elle accessible à tous les utilisateurs de Windows 11 ? Cela dépendra des tests et des retours d’expérience. Naturellement, Microsoft souhaite s’assurer que cette fonctionnalité est fiable et efficace, et qu’elle ne provoquera pas elle-même de dysfonctionnements inattendus. Si tout se passe bien, elle pourrait être mise à la disposition de tous dans les prochains mois, et certainement avant la fin de l’année.

Autres outils de récupération

Windows 11 propose toute une gamme d’autres méthodes de récupération et de reconstruction si le système d’exploitation ne fonctionne pas correctement. Un disque de récupération permet de restaurer Windows « à l’état vierge » s’il ne démarre pas, mais il ne restaurera pas vos fichiers ni vos paramètres. Une réinitialisation tente de redonner vie à Windows sans perdre vos fichiers ni vos paramètres. Une option plus récente, appelée « Quick Machine Recovery », vise à résoudre les problèmes de démarrage et, si possible, à réactiver votre système.

Microsoft propose également en avant-première une autre option appelée « restauration à un instant donné ». Dans ce cas, Windows crée automatiquement des instantanés à différents moments. En cas d’erreur système, le système d’exploitation tentera automatiquement de se restaurer à partir d’un instantané précédent. Toutes vos applications, tous vos fichiers et tous vos paramètres seront également restaurés à partir de ce moment précis.

Le choix de l’outil à utiliser dépend de la capacité de Windows à démarrer et de la nécessité ou non d’inclure vos propres fichiers et applications. Mais je me réjouis que Microsoft s’efforce de couvrir tous les cas de figure en cas de dysfonctionnement grave de Windows.
