Claude Fable 5.1 : Anthropic mise sur la baisse des coûts plus que sur les benchmarks

Ulrich Rozier

Voir l'article original

Anthropic lance Claude Fable 5.1 et Claude Mythos 5.1, ses modèles les plus avancés pour le code.

Fable 5.1 fait mieux que Fable 5 sur les benchmarks. Sans surprise. Le chiffre qui parle à une direction informatique est ailleurs : les lectures de cache coûtent 75 % moins cher que sur la génération précédente. Anthropic en tire une facture réelle allégée d’environ 25 % pour un usage courant, et jusqu’à 45 % pour les usages agentiques intensifs.

Anthropic a dévoilé les deux modèles comme ses plus avancés pour le code et le travail de connaissance. Côté chiffres, il revendique 55,8 % sur Terminal-Bench 4.0, contre 42,0 % pour Fable 5, soit près de 14 points de mieux sur ce test de code. Sur Terminal-Bench-Science 0.1, orienté sciences, le modèle passe à 52,6 %, plus du double de son prédécesseur. Par contre, le périmètre et la méthode de ces deux tests ne sont pas documentés publiquement.

Le nerf de la guerre, c’est le cache

La grille tarifaire complète de Fable 5.1 n’a pas été communiquée, du moisn pour le moment. Il est donc compliqué de reconstituer une facture au centime près pour l’instant. Le principe, lui, est simple : la lecture de cache évite de repayer le même contexte à chaque requête, qu’il s’agisse d’un long prompt d’instructions ou d’une base de code relue en boucle. Concrètement, plus l’usage répète du contexte, plus la remise pèse, d’où l’écart entre 25 et 45 %.

Sur ce terrain, la concurrence n’a pas attendu. OpenAI facture ses lectures de cache jusqu’à 90 % moins cher que l’entrée standard. Google applique une remise du même ordre sur Gemini. En rabotant à son tour le prix du cache, Anthropic rejoint une bataille déjà bien engagée. Il avait déjà misé sur le prix avec Claude Opus 5, présenté comme un modèle qui se rapproche de Fable 5 pour moitié prix.

Rassurer les grandes entreprises

L’autre chantier vise les directions informatiques. Avec les Enterprise Frontier Safeguards (EFS), Anthropic promet de tenir ensemble confidentialité et détection des usages malveillants. Les données d’activité peuvent rester dans le cloud du client (Amazon S3, Azure Blob Storage ou Google Cloud Storage), sous ses propres clés de chiffrement, sans qu’un employé d’Anthropic n’y jette un œil.

Enfin, Claude Mythos 5.1 reste réservé à la cyberdéfense et à la recherche en sciences du vivant, via des programmes d’accès restreint. On retrouve la prudence de Fable 5, bridé volontairement à son lancement, dont l’accès avait viré au casse-tête après une restriction côté États-Unis. Pour les équipes techniques, tout se jouera sur la facture réelle. On aura la réponse quand Anthropic publiera sa grille tarifaire complète.
