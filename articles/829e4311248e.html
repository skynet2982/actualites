Top 14. Les compositions de Vannes - Montpellier : Giorgi Beria à la pile, Adam Hastings à la mène

La rédaction de Rugbyrama

Voir l'article original

Vannes reçoit Montpellier ce samedi à 16h35. Pour cette rencontre, les Bretons pourront compter sur leur recrue, le pilier international français Giorgi Beria (une cape). Côté MHR aussi, une des principales recrues sera titulaire, en la personne d'Adam Hastings.

La composition de Vannes : 15. Bouthier ; 14. Surano, 13. Pi. Boudehent, 12. Nu'u, 11. Benmegal ; 10. Lafage, 9. Ruru ; 7. Gorrissen (cap.), 8. Boulier, 6. Iashagashvili ; 5. Desjeux, 4. Alemanno ; 3. Medrano, 2. Cherry, 1. Beria.

Remplaçants : 16. Sanerivi, 17. Boniface, 18. T. Mézou, 19. Edwards, 20. Blanc-Mappaz, 21. Le Bail, 22. Stevenson, 23. Schonert.

La composition de Montpellier : 15. Banks ; 14. Delibes, 13. Cadot, 12. Piccardo, 11. Rates ; 10. Hastings, 9. Bernadet ; 7. Bécognée, 8. Vunipola (cap.), 6. Camara ; 5. Duguid, 4. Verhaeghe ; 3. Japaridze, 2. Akrab, 1. Erdocio.

Remplaçants : 16. Tolofua, 17. Welsch, 18. Van Heerden, 19. Masibaka, 20. Price, 21. Hogg, 22. Vincent, 23. Hounkpatin.
