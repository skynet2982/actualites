Soutenez les écoles et Instituts du CHU de Toulouse avec la Taxe d'apprentissage

Voir l'article original

Chaque année la taxe d’apprentissage – redevable par les entreprises et réservée aux écoles et instituts – permet d’améliorer l’environnement, les techniques ou technologies qui participent à la professionnalisation des acteurs de santé de demain.

Elle permet concrètement aux instituts du CHU :

  • D’acheter de nouveaux équipements ;
  • De développer de nouvelles pédagogies plus dynamiques ou distancielles dans nos écoles ;
  • De renforcer les équipes encadrants les étudiants.

En guise d’exemples, ces dernières années la taxe d’apprentissage a permis l’acquisition de mannequins, d’ouvrages et de matériels pour les travaux pratiques au PREFMS... Cette année, c’est le financement de nouveaux matériels tels que des casques de réalité virtuelle qui est notamment visé.

Comment procéder ?

Les entreprises assujetties peuvent soutenir les centres de formation du CHU de Toulouse jusqu’au 21 octobre 2026 via la plateforme dédiée.

  1. Les entreprises doivent se rendre sur la plateforme SOLTEA pour s’identifier et affecter le versement du solde de leur taxe d’apprentissage.
    Espace des Employeurs
  2. Elles peuvent ensuite flécher leur financement auprès des structures suivantes :
  • Pour l’institut de formation aux soins infirmiers (IFSI) : code UAI 0311731N / Siret 26310012500016
  • Pour l’institut de formation aux aides-soignants (IFAS) : code UAI 0311731N / Siret 26310012500016
  • Pour l’institut de formation des ergothérapeutes (IFE) : code UAI 0311731N / Siret 26310012500016
  • Pour l’institut de formation des manipulateurs en radiologie (IFMEM) : code UAI 0311731N / Siret 26310012500016
  • Pour l’institut de formation de la pédicurie podologie (IFPP) : code UAI 0311731N / Siret 26310012500016
  • Pour l’institut de formation des masseurs kinésithérapie (IFMK) : code UAI 0311731N / Siret 26310012500016
